# Umami API

A simple proxy for self-hosted [Umami](https://umami.is), built for embedding visitor stats in static sites like [Hugo](https://gohugo.io/).

## Example

Insert this code on your Blog frontend page

```html
<script
  src="https://your-domain.com/script.js"
  defer
  init-visitors="100"
  init-views="200">
</script>
```
